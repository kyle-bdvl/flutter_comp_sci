# Step by step to upload to github 

### step 1 

``` git init  ```
this is if you didn't initialize git in your repo 

### step 2 
copy your remote address and then run 
``` 
git remote add origin
```
### step 3
```git add . ```

### step 4
```git commit -m"first project init" ```

### step 5
```git push origin -u main ```

## check your branch
``` git branch``` 
if its main then use main during your git push if its master then do 
```git push origin -u master```
